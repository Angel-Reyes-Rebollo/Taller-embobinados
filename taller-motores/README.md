# Página del taller (demo)
Ejecutar: `python main.py` y abrir http://localhost:8000 (solo requiere Python 3).

- **Datos** (nombre, teléfono, WhatsApp, dirección, horario, redes, años): bloque `CONFIG` al inicio de `js/script.js`.
- **Colores**: bloque `:root` al inicio de `css/styles.css`.
- **Imágenes**: coloca fotos en `images/` con estos nombres: taller, embobinado, motor-ac, motor-dc, motor-monofasico, motor-trifasico, bomba-agua, bomba-sumergible, bobinas-cobre, tecnico (.jpg). Si falta alguna, se muestra un recuadro "IMAGEN DEMO".
- **Textos / servicios / FAQ**: directamente en `index.html`.
- **Nueva categoría de motor**: copia un `<article class="big">` en la sección `#motores`.
